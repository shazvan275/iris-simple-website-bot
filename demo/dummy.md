# Dummy Iris Knowledge Base

This dummy markdown file is used to test Iris markdown-grounded answers for a sample event website.

The sample event opens at 9:00 AM, and guests are encouraged to arrive 20 minutes early for badge collection.

Registration is located near the main entrance, beside the welcome desk and printed venue map.

The morning program begins with a short welcome session, followed by keynote remarks in the main auditorium.

Breakout sessions run in separate rooms, and each room has signage outside the door with the current topic and speaker name.

Lunch is served in the dining area from 12:30 PM to 1:30 PM, with vegetarian and non-vegetarian options available.

Attendees can ask the support desk for help with schedule questions, venue directions, and accessibility needs.

The support desk can also help guests find lost items, contact event staff, and report technical issues with presentation rooms.

Wi-Fi details are available at the registration counter, and the event team can provide connection support if needed.

The closing session starts at 5:00 PM in the main auditorium and includes final announcements, acknowledgements, and next-step information.
